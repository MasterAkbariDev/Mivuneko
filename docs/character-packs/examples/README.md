# Manifest templates

These are complete JSON examples of the format, not bundled third-party artwork packs. Supply the exact files referenced by each manifest before importing. Keep every file path, pose mapping, anchor and usage license accurate.

- `2d/character.json`: a six-pose three-column/two-row atlas, silent by design.
- `depth/character.json`: the atlas plus a separately drawn transparent ribbon plane and an explicit server voice prompt.
- `vrm/character.json`: a self-contained user-supplied VRM and a 3-30 second voice reference with its exact transcript. Reference cloning remains a future engine.

The templates are downloadable from the dedicated in-app Creator Handbook. Full specification: `docs/CHARACTER_PACKS.md`.
