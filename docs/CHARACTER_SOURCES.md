# Character sources and expressive rendering · v0.3

## What the references demonstrate

[Kyndred](https://www.getkyndred.com/) describes character-specific voices and memory, with Maya/Rin faces, lips and gestures following dialogue. Its public site is a product reference, not a source-code or asset license. [Project AIRI](https://github.com/moeru-ai/airi) separates hearing, speech, reasoning and VRM/Live2D stages; it is a useful architectural reference. Mivuneko copies neither project's character art, private services nor branding.

Mivuneko's implementation now has separate activity (listening/thinking/speaking), emotion, body pose, mouth amplitude and head-effect layers. An angry reply can retain its facial expression while its mouth follows playback. An anger-mark sprite follows the humanoid head's world position, instead of being glued to the pet window. Tears, surprise and celebration effects use the same anchor. Reduced motion disables effect wobble and nodding. These effects are original canvas drawings generated by source code.

## Included and directly usable

**Pixiv VRM1_Constraint_Twist_Sample v1.0.1** is bundled and is the fresh-install default, selectable as “Pixiv · expressive VRM sample”. Existing character preferences are preserved. The technical sample has angry, happy, sad, surprised, relaxed, blink and five mouth expression presets, plus MToon materials, spring bones and constraints. We read its embedded metadata before including it: redistribution is permitted, avatarPermission is everyone, commercialUsage is corporation, modifications/redistribution are allowed, and antisocial/hate usage is prohibited. It is not CC0. See `licenses/pixiv-expression-sample.json` and `licenses/README.md` for attribution, source, exact SHA-256 and the applicable VRM Public License 1.0 link.

- Source and download directory: https://github.com/vrm-c/vrm-specification/tree/master/samples/VRM1_Constraint_Twist_Sample
- Official sample catalog, including **Seed-san**: https://github.com/vrm-c/vrm-specification/tree/master/samples
- License: https://vrm.dev/licenses/1.0/

The sample is rendered locally. No avatar is uploaded to Gemini. The renderer supplies an arms-down idle pose, blink, small head motion, expression presets, amplitude mouth motion and anchored effects. Authored walk/sit/dance animations are still separate assets and are not automatically supplied by a VRM's facial expressions.

## Import and verify

Menu → Pet options → Your VRM → select a local embedded .vrm, at most 50 MB. Name, author, license identifier/URL and advertised presets appear in the options panel. The file is stored only on this device and can be removed. External image/buffer URLs are rejected. Use Emotion preview to inspect happy/angry/sad/surprised/celebration on the actual model. A preset absent from the rig remains absent; the head effect can still appear independently.

To commission a production character, request a VRM 1.0 with humanoid head mapping, happy/angry/sad/surprised/relaxed/blink and aa/ih/ou/ee/oh mouth presets; embedded textures; tested spring bones; separate authored idle/walk/sit/wave clips; and explicit permission for local AI companion use and redistribution if shipping it. Exporting a nice-looking static mesh alone does not supply facial expressions or a personality.
