# Character sources

Luna uses the project's existing purple 2D artwork. Miku is an unofficial AI-generated fan-art interpretation of Hatsune Miku, a third-party character; no affiliation or character rights are implied. Kiko and Stella are original AI-generated designs created for this project. The new transparent PNG atlases each contain six poses, with further moods represented through animation and effects.

The former Pixiv VRM sample and the other 3D and SVG prototypes are no longer presented as character choices. Historical provenance for the former sample remains in `licenses/pixiv-expression-sample.json`. Imported VRM data already saved on a user's device is not deleted.

The project owner should review rights for distribution, especially for the Miku fan artwork. See [licenses](../licenses/README.md).
