# AURA Design System v0.1

## Brand and experience
Personality: playful, competent, respectful, never manipulative. Style: anime-inspired but functional. Default dark theme, optional light theme, reduced-motion mode, accessible contrast.

## Design tokens
Background #0B1020; surface #151B30; elevated #202944; primary #A78BFA; accent #5EEAD4; text #F4F6FF; muted #A8B2CC; danger #FB7185; warning #FBBF24; success #34D399.
Typography: Inter for UI, Noto Sans for multilingual fallback. Scale: 12/14/16/20/24/32 px. Spacing: 4/8/12/16/24/32 px. Radii: 8/12/16/24 px. Motion: 120–250ms for UI; character animation independently controlled; honor reduced motion.

## Screens
1. Onboarding: permissions, character, language, provider key, local model download.
2. Desktop companion: click-through floating avatar, speech bubble, mic indicator, drag handle, quick actions.
3. Chat panel: history, attachments, tool activity, mode selector, stop button.
4. Tool approval: action summary, target application, affected data, allow once/deny; optional narrowly scoped remembered permission.
5. Settings: character, voice, language, providers, privacy, permissions, model downloads, performance.
6. Activity center: tool invocations, outcomes, errors, export/delete logs.

## Character states
idle, listening, thinking, speaking, happy, curious, confused, concerned, celebrating, sleeping, error. Emotional cues are expressive fiction, not claims of sentience. Never use guilt, jealousy or coercive nudges.

## Accessibility
Keyboard navigation, screen-reader labels, captioned voice output, disable always-on-top, scalable text, no color-only status cues, microphone indicator, one-click stop.
