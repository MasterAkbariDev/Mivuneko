# Luna companion artwork

Original illustrated character artwork generated for Mivuneko on 2026-10-28.
The character design and sprite atlas were created specifically for this project;
no Kyndred character art is included. The 1536 × 1024 transparent PNG contains
six poses in a 3 × 2 grid: idle, happy, surprised, indignant, sleeping, talking.

Asset: `apps/desktop/public/characters/luna-atlas.png`.
Typography: Manrope is bundled through `@fontsource-variable/manrope`, with its
upstream SIL Open Font License included in the dependency package.

An additional matching transparent atlas, `luna-expressions.png`, adds thinking,
listening, shy, sad, celebrating and dancing poses. Both atlases are used by the
sprite-based 2D model described in `docs/LUNA_2D_MODEL.md`.
